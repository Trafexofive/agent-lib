# Mock JSON Data Suite

This relic contains a collection of 10 mock JSON files, organized into `data/` and `config/` subdirectories.

## Files Included:

*   `data/users.json`: Sample user data.
*   `data/products.json`: Sample product catalog information.
*   `data/orders.json`: Sample order details.
*   `data/posts.json`: Sample blog posts.
*   `data/comments.json`: Sample comments related to posts.
*   `data/employees.json`: Sample employee records.
*   `data/departments.json`: Sample company department information.
*   `data/tasks.json`: Sample project tasks.
*   `data/projects.json`: Sample project details.
*   `config/settings.json`: Sample application configuration settings.

## Usage

These JSON files can be used for various purposes, such as:

*   **Development & Testing:** Populating databases, mocking API responses, or testing data handling logic in applications.
*   **Learning:** Understanding JSON structure and common data modeling patterns.
*   **Demos:** Providing sample data for demonstrations or presentations.

Each file contains valid JSON and can be parsed by any standard JSON parser or library in your programming language of choice (e.g., `json` module in Python, `JSON.parse()` in JavaScript).

To use these files, simply navigate to the directory where they are created (e.g., `mock_json_data_suite/`) and access them by their relative paths (e.g., `mock_json_data_suite/data/users.json`).
