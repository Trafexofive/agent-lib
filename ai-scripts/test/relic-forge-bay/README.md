# Relic Forge Bay

This project is the foundational tool for the Chimera Ecosystem. It is a command-line utility that takes a declarative JSON plan and materializes a complete project structure from it.

It is schema-aware and can handle both the creation of new Relics (`FullRelicPlan_v2`) and the surgical modification of existing ones (`RelicModificationPlan`).

This tool is designed for direct, local use and has no external dependencies other than a standard Python 3 interpreter.

Refer to `SETUP_INSTRUCTIONS.md` for usage details.
